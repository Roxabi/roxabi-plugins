# omp-build

OMP-only delivery plugin. Owns the OMP cycle after `dev-core` is uninstalled from the live OMP machine.

## Language

**omp-build**:
The OMP-only plugin that owns the OMP delivery cycle.
_Avoid_: factory, /R-dev, /build, dev-core (on OMP)

**Sortie produite** (produced output):
A file successfully copied or generated by the current build.

**Sortie obsolète** (obsolete output):
A file present in a managed output root that is not a Sortie produite of the current build.

**UW (unit of work)**:
A unit of work identified by its repository and issue number; it may contain other UWs.

**UW parente**:
A UW with children, as determined by its native GitHub relations rather than an issue type.
_Avoid_: a delivery inferred from its children's approvals alone

**UW feuille**:
A UW without children, as determined by its native GitHub relations.
_Avoid_: a role fixed by an issue type

**UW gérée**:
A UW whose confirmed Mandate establishes an accepted Spec. A conforming body, allocated identities or native closure alone do not establish its delivery.
_Avoid_: a size label, an issue considered delivered because it is closed

**Terminée**:
A calculated state backed by authenticated delivery: a merged bound leaf with a successful `review` check on its merged head or admissible historical structured-review proof; a parent also needs completed accepted children, matching relations, coverage and direct integration evidence.
_Avoid_: native closure, an abandoned UW, the sum of child approvals

**Feature**:
Leaf UW delivery under a live mandate. `/feature` prepares authority and the worktree; the session composes implementation, independent review and correction, resumes from Git and GitHub facts, and uses guarded delivery effects. Parent delivery is suspended until #1031 slice 6.
_Avoid_: build, /build, /dev, /R-dev, omp-wt

**Mandate**:
The operator's accepted authority to deliver or correct a defined scope under a specified configuration. A correction-only mandate does not authorize landing.
_Avoid_: a session goal, a review verdict, a permission inferred from missing data

**Pause**:
Temporary suspension of an otherwise valid Mandate, confirmed only after the applicable landing arms are cleared. Resumption does not clear a review-bound or safety stop.
_Avoid_: abandonment, a spent bound, stopping the local process

**Abandonment**:
Explicit revocation of a Mandate, not successful completion and not removal of incoming dependencies. A successor, if one exists, retains its antecedents and does not erase their stops.
_Avoid_: pause, automatic renewal, resetting a bound

**Successor**:
A mandate that names an abandoned or revoked antecedent on the same issue. An open pull request stays the same request, rebound to the successor.
_Avoid_: automatic renewal, a second issue, a second pull request, `/feature <reference>`

**Operator control**:
A confirmed record that pauses, resumes, abandons, names a successor, or records an explicit material-Spec decision. A local process stop is not this record.
_Avoid_: a session goal, an unconfirmed inhibit

**Review interruption**:
A historical record that ends an interrupted initial review inventory without a verdict. It preserves the original root and inputs.
_Avoid_: Request changes, Approve, abort-as-verdict, rewriting the historical root

**Replacement grant**:
A historical record authorizing one linked replacement review after a Review interruption. Only a confirmed linked inventory consumes the grant.
_Avoid_: a new Review bound, erasing historical attempts, automatic third recovery

**Replacement review**:
A historical review attempt linked to a Replacement grant and the interrupted root. Only a completed final counts toward the legacy Review bound.
_Avoid_: treating it as a first attempt, treating a genuine Request changes as a third recovery

**Action receipt**:
A confirmed START or RESULT record for a historical action. Plan and implementation receipts remain evidence, not a cursor for composed delivery.
_Avoid_: a review record, a transcript, a local cache

**Workflow binding**:
The confirmed link on a pull request to one mandate, branch, and base. It adds no permission.
_Avoid_: a closing keyword, a branch name, a body parse

**Additional requirements**:
The string list at `review.additional_requirements` in committed `.dev/stack.yml`, recorded on the mandate. It is not a graph, a bound, or an admission rule.
_Avoid_: `.omp-build/workflow.json`, a working-tree copy, `review.graph`, `review.workflow`

**Confirmed checkpoint**:
A published effect whose remote record or native facts have been read back. Composed Feature uses current Git and GitHub facts rather than a saved workflow checkpoint.
_Avoid_: a local snapshot, an attempted write, an unconfirmed acknowledgement

**Parent UW mandate**:
The confirmed mandate on a UW parente: the accepted child UWs, their Spec versions and tiers, and their parent coverage for one delivery. It is not a session goal.
_Avoid_: /goal, an autonomy level stored on the issue, one goal per UW

**Run**:
The coordination identifier retained on a Parent UW mandate. It identifies the historical delivery pass without granting authority or resetting a legacy review bound.
_Avoid_: Goal run, a /goal line, `run=` in an objective, a counter of attempts

**Arrêt d'UW**:
A historical parent-delivery stop confined to one child UW while independent children could continue.
_Avoid_: a shared-state stop, a /goal drop, a stop held only in session memory

**Shared-state stop**:
A historical parent-delivery stop that made all remaining children unsafe to continue.
_Avoid_: an Arrêt d'UW, a /goal, waiting on pending base CI before a child UW

**Spec**:
The versioned framing of a UW: criteria, invariants, exclusions, open questions, and named context sections. Its proposal is carried by the issue body; acceptance belongs to the existing mandate and operator-decision chain.
_Avoid_: artifacts/specs, validated, /R-spec, acceptance inferred from a body edit

**Spec propre**:
The framing authored for one UW, distinct from obligations inherited from its ancestors.
_Avoid_: an ancestor's Spec, an inherited body concatenation

**Spec proposée**:
The framing offered by the current issue body. A conforming proposal is not acceptance.
_Avoid_: the accepted Spec, authority inferred from a manual edit

**Spec acceptée**:
The immutable framing version established by the confirmed mandate and its authenticated acceptance chain. A newer proposed version does not replace it implicitly.
_Avoid_: the latest body, an identity allocation, a local approval flag

**Référence de Spec**:
The UW identity, canonical content version and confirmed source that accepted that version.
_Avoid_: a body URL alone, an unversioned obligation

**Version de Spec**:
The identity of parsed canonical framing content, independent of presentation-only spacing and distinct from the integrity of the exact source bytes.
_Avoid_: a raw-body digest, whitespace erasure inside an obligation or example

**Vecteur de versions acceptées**:
The ordered accepted Spec references for a UW and every ancestor, starting with the UW itself. It pins the obligations used together rather than following newer proposed bodies implicitly.
_Avoid_: an own-only reference, an unversioned ancestor list, implicit acceptance of a parent edit

**Couverture parente**:
The explicitly accepted assignment of every parent criterion to at least one accepted child, at the accepted Spec versions and tiers. Child approvals alone do not establish that the parent's integrated criteria are satisfied.
_Avoid_: matching criteria by text, implicit coverage, an orphan criterion

**Critère**:
A UW obligation with a durable identity that survives rewording and is never reused after withdrawal.
_Avoid_: an identity inferred from matching text, an untracked bullet

**Invariant**:
A durably identified rule that must remain true throughout a UW's delivery.
_Avoid_: an optional criterion, an exclusion

**Exclusion**:
Additional work explicitly outside a Spec version's scope, cited within that version rather than by a durable criterion identity. It never permits a regression or an invariant violation.
_Avoid_: permission to break compatibility, a satisfied criterion

**Historique d'identités**:
The durable allocation and withdrawal history of a UW's criteria and invariants. It establishes identities, not acceptance of a Spec.
_Avoid_: the current body alone, a second accepted-Spec registry

**Cadrée**:
A UW whose applicable framing has a tier, at least one criterion and no open question.
_Avoid_: syntax validity alone, an accepted delivery

**Livrable**:
A UW whose applicable Spec is framed and whose required graph facts and dependencies permit delivery.
_Avoid_: completed, native issue closure, an earlier admission reused without checking

**Wayfinder**:
A navigation map and its decisions for a path that needs exploration beyond one delivery. They are not UWs, have no UW tier and are excluded from the UW work graph.
_Avoid_: an accepted child silently removed by reclassification, a completed blocker inferred from a label

**Spec effective**:
The target applicable framing: the UW's own accepted Spec together with its ancestors' invariants and exclusions, pinned by their references and versions.
_Avoid_: the own Spec alone, an unversioned body concatenation, treating a missing ancestor as empty

**Issue**:
The GitHub support for a proposed Spec, native graph facts, records, and the display of a UW.
_Avoid_: the UW itself, proof of delivery from native closure

**Report**:
An immutable record retaining an untreated cause, finding or rule error on its UW of origin with its reason and code version. It is readable for that UW and its descendants. Promotion requires operator confirmation and fresh creation admission; it is suspended under an active parent.
_Avoid_: an automatically created follow-up issue, global search without an index, a satisfied criterion

**Instantané**:
A read-only dossier of pinned inputs for one action, providing its UW data, references and an index of obligations and files. It exposes the action's exact assessment or CI-attribution operands when applicable, and relevant pinned repository instructions and glossaries. Its local byte integrity is distinct from the durable identity of the action's inputs.
_Avoid_: a dev-core snapshot, a mutable cache, an independent operand authority, the durable review fingerprint

**Manifeste d'entrées**:
The durable, portable identities and versions of the inputs actually supplied to an action, including its code, effective Spec, delivery data, pinned references and applicable exact assessment or CI-attribution operands. Its canonical digest identifies those inputs independently of the local Instantané and excludes the action's own outputs.
_Avoid_: the local dossier's byte digest, a PR description, a list that silently omits supplied context

**Contexte élargi**:
Additional pinned inputs supplied to a newly prepared action after necessary information was reported missing. They do not change accepted obligations or grant execution or publication authority.
_Avoid_: silently modified inputs, a renewed mandate, a satisfied criterion

**Données de livraison**:
Versioned declarations, evidence and verdicts associated with obligations and the code examined. An action explicitly identifies the data it consumes; its resulting verdict is not its own input.
_Avoid_: an unobserved claim, a successful command without its result, conversation history copied as proof

**Canonical record**:
A versioned common record whose payload is the authority for that operation. The Markdown beside it is a deterministic projection, not a second contract.
_Avoid_: a positional HTML marker, a Markdown section a consumer parses, a local session store

**UW event**:
A historical `epic-event` record on a parent or child UW. `goal-stop`, `epic-review`, `post-merge` and `goal-report` remain readable; `epic-fix` is diagnostic only. None restarts parent delivery.
_Avoid_: a /goal, a body marker, a `goal-stop` comment prefix, session memory

**Legacy hosted admission**:
The structured check used by the separate trusted CI auto-merge gate. It requires authentic approval of the current head, an unspent native review bound, admissible CI, unchanged inputs and applicable UW authority. It is not composed Feature's merge lock.

_Avoid_: a green check alone, an earlier review, an unbound head, treating a digest as authentication

**TDD**:
Test-first implementation at the seams agreed with the operator, using the model-invoked `tdd` skill.
_Avoid_: automatic tests for every change, a mandatory user slash

**Implementation**:
Work that satisfies one UW's acceptance criteria inside its matching Worktree.
_Avoid_: an external `implement` skill as a prerequisite, implementation on the Principal

**Land**:
The one head-pinned merge of a bound PR through the Feature delivery CLI under the GitHub `review` + `ci` ruleset. The CLI does not arm auto-merge.
_Avoid_: manual merge while checks run, treating a label as a completed landing

**Finish**:
The `closeLinked` transition that closes a delivered leaf after the bound merge and its delivery proof are confirmed. The composed proof is a successful `review` check on the merged PR head, not native issue closure.
_Avoid_: a second merge, a closing keyword, using the base or merge-commit SHA as the reviewed head

**Review verdict check**:
GitHub's `review` check for an exact PR head, produced from an approved `review-verdict v1` line. A new head needs a new verdict.
_Avoid_: a `reviewed` label, a green check on a different head, a canonical native review record

**Post-merge hook**:
Historical parent-delivery hook on the integrated base commit, not on each child's merge. Its old result is not live parent delivery authority.
_Avoid_: a per-child deploy, a release cut, re-running this run's hook on a moved base

**Review bound**:
The legacy native cap of two automated corrections per PR, derived from complete canonical final review records. A spent bound remains stopped and disarmed; revised scope requires explicit operator supervision and fresh admission on a superseding PR. Composed Feature instead permits two automatic correction rounds per invocation.
_Avoid_: a ledger, counting fix receipts, resetting a canonical stop, one more automatic retry, raw label or manual-merge bypass

**dev-core snapshot**:
A frozen copy of selected `dev-core` files inside `omp-build`. No resync. Claude's `dev-core` evolves alone.
_Avoid_: Instantané, fork, submodule, live share

**Lien d'UW**:
A native GitHub relation between UWs: sub-issue (parent/child) or dependency (blocked-by/blocks). Automated omp-build issue mutations, including relations, pass through UW operations; standalone issue-triage remains independent.
_Avoid_: a `Blocked by:` text line, `.scratch/` local edges, raw `gh issue create` for a relation

**Cause disposition**:
The evidence-backed decision for one cause. A blocking cause is necessary and urgent by definition; uncertainty keeps it blocking rather than authorizing an automatic correction or report.

| Established cause | Disposition |
|---|---|
| Blocking, missing or contested evidence | Pending motivated operator adjudication; not a final disposition |
| Necessary and urgent, fits the original UW | Fix in the original UW |
| Blocking, too large | Confirmed sister UW; original waits for sister |
| Nonblocking, necessary and urgent, too large | Confirmed sister UW after original |
| All other established causes, including unsupported nonblocking work | Report on original UW, no issue |

An exclusion covers only explicitly excluded additional scope, never a regression, security defect or invariant violation. A sister shares the original's parent and needs confirmation of its exact framed proposal. Creation under an active parent is suspended.
_Avoid_: an automatic nonblocking bundle, a blanket sibling rule, treating a pending blocker as a final report, clearing a missing criterion by rejecting a finding

**Tier**:
`S` | `F-lite` | `F-full`, read from the UW's native GitHub `size:` label. Determines the review's spec-evidence requirements, not its agent roster.
_Avoid_: spec frontmatter, κ alone, tier-selected review agents

**issue-triage**:
The standalone tracker plugin creates issues and writes labels and native relations. In omp-build, automated issue body, label, relation, and state writes are owned by UW operations.
_Avoid_: treating standalone issue-triage as omp-build's authority

**Optional tail**:
`cleanup` after confirmed `finish`, plus `promote` for staging-train projects only. Both remain the operator's decision.
_Avoid_: putting them in the review loop

**dev-core**:
The Claude/Grok factory plugin. Source stays in the marketplace; it is not loaded on OMP after the cut.
_Avoid_: "the plugin" when the host is OMP

**Dark-to-model**:
A skill omitted from the prompt listing by `disable-model-invocation`, but still readable explicitly. Reading a skill grants no authority.
_Avoid_: unloaded, unavailable

**Principal**:
The first `git worktree list --porcelain` worktree. Read-only exploration and tracker framing can start here; feature file edits belong in a matching Worktree.
_Avoid_: main, staging, master (those are bases, not this worktree)

**Worktree**:
A durable linked git checkout (ω) that isolates delivery from the Principal. Created from a fresh `origin/<base>`, meaning `refs/remotes/origin/<base>`. The operator enters it with `/move <path>`, not `/wt`.
_Avoid_: branch; Isolation (ephemeral `task.isolated` sandbox); `/wt`; a session goal

**Parent UW worktree**:
The linked checkout historically shared by a parent's delivery hierarchy. Nested parents had separate mandates but no separate parent branches or PRs; each leaf used its own branch and PR. Parent delivery is currently suspended.
_Avoid_: one worktree per child UW, a parent branch, the Principal, Isolation

**Bootstrap**:
The environment prepared from repository declarations in the canonical Worktree before delivery. It is rebuildable and grants no business authority.
_Avoid_: a hand-maintained checklist, copying the Principal's uncommitted state

**Init**:
A repository's adoption by `/feature`: its tracker contract, canonical labels and declared stack blocks.
_Avoid_: R-dev-init, assuming every repository is already adopted

**Isolation**:
An ephemeral `task.isolated` sandbox for a subagent. Torn down at yield; patches or cherry-pick land on the parent cwd. Not a Feature Worktree.
_Avoid_: ω, /wt, omp-wt

**Guard**:
In-process OMP `tool_call` interceptor (principal freeze, bare `bun test`, secret scan).
_Avoid_: hook (Claude `hooks.json`), lefthook (commit/push persist law)

**dev-review**:
Independent review of an exact open PR head. Reviewer agents leave findings on the PR and emit a verdict line only on approval. `/feature` follows these instructions in-session.
_Avoid_: R-dev-review as the skill name, code-review (Matt), /review (host builtin)

**dev-fix**:
The correction skill on OMP: implementer agents fix the latest `/dev-review` findings and failing checks on an open PR head, push the exact tip, then hand off to `/dev-review`. Correction never posts a verdict or merges.
_Avoid_: fixing without a current review of the head, a self-review

**Correction owner**:
The accountable holder named in a historical `fix-owner` record. A transfer does not replace the request or decision or reset a bound.
_Avoid_: the request itself, an agent session, a retry allowance, proof that every writer has ended

**Bounded correction recovery**:
A historical `fix-recovery` record of operator-confirmed neutral closure before entry or transfer of an unstarted request with its unchanged decision. It does not authorize a new attempt.
_Avoid_: a resumed patch, post-push completion, a free lock as permission

**Root cause**:
The shared mechanism behind one or more review findings, stated with its one plan: mechanism, fix, failure scenario, restored behaviour, affected paths, proof and findings. Named after the review, before any edit. Its cited necessity, urgency and size determine the cause disposition; a finding label alone does not authorize execution.
_Avoid_: the finding itself, a class slug alone, a file, a menu of solutions

**Review record**:
The historical canonical `review` payload, read by record identity. It names the decision, candidate SHA and input digest. Complete authenticated finals count toward the legacy bound and may support historical delivery proof; they are not the composed `review` check.
_Avoid_: `<!-- omp-build:code-review -->`, a line-2 head marker, scraping `## Code Review`, reading a SHA from projection prose

**Review input binding**:
The SHA-256 on a historical canonical review, or null. Prefix `omp-build:review-input/4` covers the observed code and semantic inputs, not the review outputs. A null input is not approval. Admission reconstructs the input and requires equality; the digest checks inputs, not authorship.

Missing or older input formats refuse with `incompatible-format`; they are not migrated, re-reviewed, or exempted.

_Avoid_: a line-3 HTML marker, an acquisition attestation, a cached snapshot, a digest rebound after review

**R-adversarial**:
A read-only reviewer profile for red-team and OWASP analysis. The session chooses agents for the review.
_Avoid_: reviewer, security-reviewer, a second unprefixed `adversarial`

**R-advisor**:
Read-only constructive second opinion. Not the session WATCHDOG.
_Avoid_: advisor.enabled, WATCHDOG

**elon**:
Read-only Algorithm posture (inventory → delete → simplify → accelerate → automate last).
_Avoid_: R-elon, Musk roleplay
